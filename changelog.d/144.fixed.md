- A conflict a merge driver left without markers now reaches a human instead of being staged as a resolution. A driver `.gitattributes` names that exits non-zero leaves git's three index stages set while the working copy holds whatever the driver wrote, so the structural pre-pass read the one side sitting there as a finished merge and dropped the other with nothing in the diff to show it.
- A conflict written with CRLF line endings now counts as conflict markers. Git writes each marker with the file's own line ending, so a committed `=======` followed by a carriage return read as ordinary text and the damaged file reached no pass at all.
