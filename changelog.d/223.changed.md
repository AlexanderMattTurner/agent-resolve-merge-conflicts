- The resolver now resolves a conflicted ready pull request whatever its head branch is named, and never a draft: a consent label (`approved`, `force-queue`) no longer exempts one, so approving many drafts buys no paid resolve. The `SESSION_BRANCH_PREFIXES` variable and the `session_branch_prefix` shared name are gone. The labeler reads a new `READY_FOR_REVIEW=true` input: pass it on a `ready_for_review` event so a draft that turns ready is dispatched at once.
