- The resolver merges the base branch's current tip into a resolution immediately before pushing it, so a trunk that moved during the 30-to-90-minute resolve no longer leaves the pushed head conflicted on arrival. Where the new commits conflict with the resolution, the run pushes nothing, leaves the head unmarked, and dispatches one fresh resolve against the new base.
- The merge-delta reviewer no longer raises a blocking finding on a top-level definition the pull request's own branch deleted. A new trusted annotation names every definition the merge base bound, a parent deleted, and the merged file no longer binds.
