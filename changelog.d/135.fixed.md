- The resolver strips a formatter's column padding out of a conflicted markdown table and re-merges the rows, so a small disagreement no longer arrives as a whole-table conflict.
- That pass rewrites padding and nothing else: it keeps a data cell of hyphens, the row's indentation and the file's line endings, and it leaves alone a table inside a code fence, a path whose `.gitattributes` names a merge driver, and a generated region another pass deferred.
