- The per-file resolution shards and the pre-push merge-delta self-review now run `claude-sonnet-5` instead of `claude-opus-5`, and a new `review-model` input names the model that pre-push pass runs. It is separate from `model` on purpose: that one lowers the shards to save cost, and this pass judges those shards and can refuse the push, so lowering one never lowers the other. Raise `review-model` when no CI of yours reads the pushed delta, because the pass is then the only read your merges get.
- Keep `self-review` on even when your own CI gates the pushed delta. The pass fixes before the push, so it saves the review cycle your own reader would otherwise spend; `self-review: false` now means only that you want no pre-push model call.
