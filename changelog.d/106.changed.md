- The pre-push merge-delta self-review now runs by default. A caller that names no `self-review` input gets it, so an adopter never pushes a merge that nothing reads. It refuses the push on a finding it cannot fix. It lands the merge marked unverified, with auto-merge disabled, when it reaches no model — whether the credential rungs answered and failed, or none is configured at all. A bundle a prior run produced with the review off records neither outcome, so a reuse of it is refused and the resolve runs again from what that bundle salvages. Pass `self-review: false` when CI of yours already reads the pushed delta and gates the merge on the finding.
