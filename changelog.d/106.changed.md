- The pre-push merge-delta self-review now runs by default. A caller that names no `self-review` input gets it, so an adopter never pushes a merge that nothing reads. It refuses the push on a finding it cannot fix, and it lands the merge marked unverified when no credential rung answers. A bundle a prior run produced with the review off records no such read, so a reuse of it is refused and the resolve runs again from what that bundle salvages. Pass `self-review: false` when CI of yours already reads the pushed delta and gates the merge on the finding.
