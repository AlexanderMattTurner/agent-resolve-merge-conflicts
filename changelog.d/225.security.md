- `merge-delta-review.yaml` runs its model in a job that holds only read scopes. A new `publish` job holds `pull-requests: write`, runs no model, and posts the verdict. `publish` carries the check-run name `Review the PR's merge-resolution deltas`, so a gate that matches that suffix still sees a green check only when the verdict reached the pull request.
- No `claude` process the resolver starts inherits a GitHub token. The shards and the self-review drop `GH_TOKEN`, `GITHUB_TOKEN` and the enterprise names from the model's environment.
